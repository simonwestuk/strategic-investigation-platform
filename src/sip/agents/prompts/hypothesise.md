# Task: generate competing hypotheses (Hypothesis Generator) — v1

Generate 8 to 14 competing hypotheses that could explain the framed question. Avoid premature
convergence: include explanations that compete with each other, internal and external causes, and at
least one that would be uncomfortable for the organisation's leadership.

Each hypothesis must use one `category` from the provided driver taxonomy (use the category id). You
may set `segment` to an entity code from the dataset descriptions when a hypothesis is specific to one
segment; otherwise leave it null. For each, state what evidence would support it and what would
contradict it, suggested source types, and a priority.
