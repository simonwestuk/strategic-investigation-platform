# Architecture

## Product principle

**Autonomous research. Governed reasoning. Human decisions.**

The platform separates sources, evidence, claims, hypotheses, recommendations and human decisions. The graph may autonomously investigate and challenge evidence, but consequential decisions remain human-owned.

## Initial graph

Question -> Frame -> Hypotheses -> Research Plan -> Research -> Analysis -> Challenge -> loop if needed -> Synthesis -> Governance Gate -> Human Decision Room.

## Privacy boundary

Confidential inputs pass through a privacy gateway before they can enter agent context. The public repository demonstrates this with synthetic data and a deterministic local detector; the Azure adapter will add Azure AI Language PII and policy-driven sensitivity handling.
